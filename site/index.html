기능

창을 바꾸지 않고, 세션을 넘나들다

◱

프로젝트 단위 세션

프로젝트를 먼저 등록하고, 그 트리 아래에서 별명 있는 세션을 만들고 전환합니다. 목록은 접고 펼칠 수 있어요.

▦

탭 · 분할 패널

터미널을 탭으로 관리하고, 2개 이상의 패널로 분할해 여러 세션을 동시에 봅니다. 드래그 앤 드롭으로 위치 조정.

⊟

Screen 그룹

사이드바 SCREENS에서 Screen 1 (A+B+C) 형태로 분할 그룹을 확인하고 정확한 화면으로 전환. 중복 레이아웃은 시작 시 자동 복구.

⌘

터미널 조작

Ctrl+C 선택 복사 · Ctrl+V 붙여넣기 · Ctrl+휠로 글자 크기 확대/축소. 익숙한 방식 그대로.

▤

Markdown 문서 패널

오른쪽 Docs 패널에서 List · Tree · Hide 모드로 문서 탐색. 터미널에 출력된 .md 경로를 클릭해 바로 열기.

◐

테마 · 업데이트

Soft · GitHub · Warm · Light 앱 테마. GitHub Releases 기반 수동 업데이트 확인. 그룹을 Codex/Claude 세션 ID에 고정.

구성

세 개의 영역, 하나의 흐름

01 — Left

사이드바

접이식 프로젝트/세션 트리, Markdown 패널 토글, 설정, 새 세션 추가.

02 — Center

작업 영역

탭과 분할 터미널 패널. 드래그로 재배치하고 Screen 그룹으로 전환.

03 — Right

Docs 패널

프로젝트 Markdown 문서 목록과 렌더링 미리보기. 터미널 영역과 크기 조절 가능.

스택 Electron · React · TypeScript · Node.js
