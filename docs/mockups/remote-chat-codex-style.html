장문 결과 스트레스 테스트

세션 결과를 길게 읽어도 흐름이 무너지지 않습니다.

내용이 긴 결과는 한 덩어리로 밀어 넣지 않고 제목·목록·코드·표·파일 결과로 나눕니다. 사용자는 필요한 부분만 펼치고, 현재 위치를 잃지 않은 채 최신 결과로 이동할 수 있습니다.

1. 결과 요약

이번 작업은 Remote 대화의 자동 갱신과 레이아웃 전환을 검토하기 위한 예시입니다. 장문 결과도 기본 폭 안에서 읽히며, 폭이 넓은 자료는 해당 블록만 가로 스크롤됩니다.

  • 결과 이벤트를 받으면 작업 로그를 펼치지 않아도 결과 카드가 즉시 추가됩니다.
  • 사용자가 이전 메시지를 읽는 중이면 화면을 강제로 끌어내리지 않고 최신 이동 버튼만 표시합니다.
  • 파일 결과는 파일명·경로·크기·열기 동작을 한 카드에서 확인합니다.

2. 처리 단계

  1. 세션별 이벤트 순서를 확인하고 마지막으로 렌더링한 결과와 비교합니다.
  2. 새 결과가 확인되면 메시지 스트림과 세션 저장소에 함께 기록합니다.
  3. 현재 스크롤이 최신 위치인지 판단한 뒤 자동 이동 또는 알림 버튼을 선택합니다.
  4. 긴 도구 로그와 부가 데이터는 접힌 상태로 남겨 본문 가독성을 지킵니다.

3. 넓은 코드 블록은 블록 안에서만 스크롤

const result = await sessionStore.readSince(cursor, { includeToolLogs: true, includeArtifacts: true, preserveScrollAnchor: true });

Remote 대화 UX 시안 메모

대화 화면을 보고 있는 동안에도 결과 이벤트를 별도 상태로 수신하고, 결과가 도착하면 메시지 스트림에 바로 삽입하는 흐름을 가정했습니다.

즉시 반영작업 펼침 여부와 관계없이 결과 카드가 현재 대화 위치에 나타납니다. 사용자가 위쪽을 읽는 중이면 “새 결과” 버튼만 조용히 표시합니다.
작업 로그 분리도구 호출·파일 수집·검증 같은 세부 과정은 Worked for 행 아래로 접어 긴 로그가 대화 가독성을 깨지 않게 합니다.
세션 상태 탭파일·소스 제어와 같은 우측 사이드바 탭으로 제공합니다. 별명·모델·연결·수명주기·경로·동기화 상태는 현재 선택한 대화 패널을 따라 갱신되며, 완료·질문·오류는 탭 배지만 바꾸고 사이드바를 강제로 열지 않습니다.
모바일 대응모바일에서는 세션 목록을 햄버거 드로어로, 우측 사이드바를 별도 오버레이 드로어로 엽니다. 둘을 닫으면 대화 컬럼과 입력창이 화면 전체 폭을 사용합니다.
좌우 분할각 세션은 독립된 스크롤·상태·입력 영역을 갖고, 우측 세션 상태 탭은 마지막으로 선택한 패널을 따라갑니다. 사이드바를 접으면 대화 폭을 회수하고 좁은 화면에서는 두 대화를 세로로 쌓습니다.
장문 결과제목·목록·결과 카드로 본문을 나누고, 넓은 코드와 표는 해당 블록 안에서만 가로 스크롤합니다. 긴 도구 로그는 기본 접힘으로 두며, 사용자가 위쪽을 읽는 중이면 최신 이동 버튼으로만 알립니다.
