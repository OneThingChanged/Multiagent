# MultiAgent App

This directory contains the Electron + React + TypeScript desktop app.

## 한국어

루트 `README.md`에 프로젝트 전체 설명이 있습니다. 이 폴더는 실제 앱 소스와 빌드 설정을 담고 있습니다.

### 개발 실행

```bash
npm install
npm run electron:dev
```

### 릴리즈 빌드

```bash
npm run electron:dist
```

빌드 산출물은 `electron-dist/` 아래에 생성됩니다.

## English

The root `README.md` contains the full project overview. This directory contains the actual app source code and build configuration.
